# Vendor blobs and HAL audit — ugglite / Mi8937

Audit date: 2026-11-19
Source family: Mi-Thorium Android 15 `a15_qpr2/master`, kernel 4.19 product.

## Executive result

The source tree contains explicit ugglite-specific camera tuning and camera binary modules, but the overall vendor stack is legacy Qualcomm/Xiaomi proprietary software. It is not yet demonstrated compatible with Android 15. Treat this as a high-risk compatibility port, not a ready-to-build or bootable ROM.

## Findings

### Camera — partial device-specific evidence, high risk

- The unified device product installs the `xiaomi_ugglite_overlay` package.
- The Mi8937 vendor makefile contains a distinct `ugglite` overlayfs camera configuration path.
- The same vendor makefile contains many `ugglite_libchromatix_*` and `ugglite_libmmcamera_*` packages. The observed tuning includes Samsung S5K5E8 / OEF0501 variants.
- The device package list includes generic camera packages (`camera.land`, `camera.prada`, `camera.ulysse`, `camera.wingtech`) rather than a clearly named `camera.ugglite` package. Need inspect camera helper repositories and runtime property selection before assuming the correct service/config is selected for ugglite.
- For kernel 4.19, `TARGET_SUPPORT_HAL1 := false`. Legacy Camera HAL1 compatibility is therefore not enabled by this product configuration.
- The extraction script applies binary fixups to camera daemons and libraries: path rewrites from `data/misc/camera` to `data/vendor/qcam`, library dependency replacement, and shim injection. These transformations show that the legacy camera stack needs compatibility work even in its intended ROM environment.

**Gate:** identify the exact physical rear/front sensor modules and camera EEPROM from the actual ugglite handset; map those IDs to the vendor tuning packages; inspect the matching camera helper project; then validate camera service startup and capture on real hardware. No camera functionality is guaranteed yet.

### Audio — legacy proprietary stack, unverified

- Device `device.mk` copies audio mixer path and platform-info XML files into ODM.
- Common vendor makefiles install Qualcomm audio libraries and related services.
- This is evidence of a populated audio configuration, not proof that audio routing, microphone, headset, VoIP, or Bluetooth audio work on Android 15.
- Need match mixer XML and sound-card names to the actual ugglite kernel DTS/ALSA topology.

### Bluetooth — common Qualcomm vendor dependencies

- Common proprietary vendor makefiles install QTI Bluetooth HIDL implementation/service components and Bluetooth SAR libraries.
- They also install vendor init rules for the QTI Bluetooth service.
- Runtime compatibility with the Android 15 Bluetooth framework and the device firmware has not been tested.

### Wi-Fi — firmware/Prima path still needs matching

- The kernel manifest declares the Qualcomm Prima WLAN project.
- Common vendor package lists include XT Wi-Fi components and configuration.
- Need verify the exact WLAN chip/module, firmware files, kernel module name, board data, and regulatory database on the handset. A manifest project alone does not prove Wi-Fi will initialize.

### Graphics / display — major unresolved area

- The product inherits Qualcomm CAF common definitions and exposes OpenGL ES / Vulkan feature declarations.
- The proprietary common vendor makefiles include Qualcomm platform components, but this audit has not yet verified the complete Adreno 308 userspace driver, EGL/GLES/Vulkan libraries, gralloc/mapper, composer, display HIDL/AIDL interface, and kernel KGSL pairing.
- Do not claim GPU acceleration or smooth UI until the exact userspace/kernel ABI pairing is confirmed and tested.

### Fingerprint — legacy Goodix path with explicit binary shims

- The extraction script contains dedicated fixups for Goodix fingerprint binaries, including HIDL library replacement and binder/logging shims.
- Board configuration includes ODM/vendor fingerprint SELinux policy directories.
- Exact ugglite sensor and service selection remain to be checked against the real handset.

### Vendor security level — significant age gap

- The device BoardConfig declares `VENDOR_SECURITY_PATCH := 2017-04-01`.
- This is a very old vendor security patch level relative to Android 15. It is a compatibility and security concern and must not be represented as a current patch level.
- Do not simply change the property to a newer date: that does not update proprietary binaries or fix vendor vulnerabilities.

## Extraction provenance and licensing

- The device `extract-files.sh` delegates to the shared `mithorium-common` extraction script.
- The vendor makefiles are generated by the extraction scripts and refer to proprietary binary payloads.
- The vendor repository's generated makefile alone does not establish the original handset firmware build, region, firmware package, or checksums for every blob.
- Before a reproducible build, record the extraction source device/firmware, source build fingerprint, blob file hashes, and the exact extraction script commit. Do not copy proprietary blobs from an unrelated Xiaomi device.

## Required next checks

1. Inspect `proprietary-files.txt` or the source blob manifest used by the common extraction script and establish blob provenance.
2. Inspect the ugglite camera overlay and helper project; confirm sensor IDs against a real device.
3. Audit ALSA sound card, mixer paths, audio policy, and audio HAL dependencies.
4. Identify Wi-Fi chipset, Prima module, firmware and board-data mapping.
5. Complete Adreno 308 KGSL/userspace driver and display HAL ABI audit.
6. Verify fingerprint sensor/service and SELinux policy.
7. Compare all vendor interfaces against the Android 15 framework; build-time success alone is insufficient.
8. Test each hardware subsystem on the physical ugglite before any daily-use claim.

## Safety status

No flash, recovery, repartition, firmware write, or device-side command is part of this audit. The physical handset is currently unavailable, so device-specific sensor IDs, firmware, partition map, and runtime HAL behavior remain unverified.
